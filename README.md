# 30 Days Challenge

A personal **30-Days of Coding / Machine Learning / Data Science** challenge repository, where I attempt one data / ML / NLP project per day.  
Each “DayX.py” file corresponds to a specific mini-project or experiment.

## 📂 Repository Structure

- `Day1.py`, `Day2.py`, …, `day30.py` — daily code scripts / notebooks  
- `ratings.csv`, `essays.csv`, `spam.csv`, `WA_Fn-UseC_-HR-Employee-Attrition.csv`, `har_data.csv` — datasets used in various days  
- Other supporting files (if any)

## 🧠 Purpose & Motivation

- Push myself to build, explore, and learn new techniques daily  
- Gain hands-on exposure to different areas: 
  - Recommender systems (using ratings)  
  - NLP / text scoring  
  - Classification / regression tasks  
  - Time series, etc.  
- Build a portfolio of small but meaningful projects  

## 🔧 Technologies & Libraries Used

- Python  
- pandas, numpy — data manipulation  
- scikit-learn — modeling, preprocessing, evaluation  
- matplotlib, seaborn — visualization  
- (Attempted) Hugging Face Transformers / PyTorch — for deep learning / NLP tasks  
- Others as required by each day’s task
